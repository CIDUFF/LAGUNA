Bem-vindo ao SIMAL

Sistema de Monitoramente de Águas Lagunares

Esta plataforma tem como objetivo melhorar a gestão dos processos de coleta e análise de amostras das lagunas de Maricá.

Este projeto foi desenvolvido pelo Centro de Inteligência de dados do Projeto Lagoa Viva.

Algumas das ferramentas disponíveis no sistema:

- Agendamento de campanhas de coleta

- Visualização de amostras coletadas

- Relatórios de análises

- Mapa de pontos de coleta

- Gráficos de análises
